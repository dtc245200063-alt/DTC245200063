# Đề 3: Website Quảng bá Sản phẩm (WordPress)

## Thông tin sinh viên
- Họ và tên: Lương Việt Anh
- Mã số SV: DTC245200063

## Hướng dẫn chạy hệ thống
1. Đảm bảo máy đã cài đặt Docker và Docker Compose.
2. Clone repository này về máy.
3. Mở Terminal tại thư mục chứa code và chạy lệnh:
   `docker compose up -d`
4. Truy cập các dịch vụ qua các địa chỉ sau:
   - Website WordPress (Nginx Proxy): http://localhost
   - Quản lý Database (phpMyAdmin): http://localhost:8080
   - Hệ thống giám sát (Grafana): http://localhost:3000
   - Prometheus: http://localhost:9090
